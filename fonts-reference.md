## System Fonts

| Font                                                        | Stack Type | Usage                                          |
|-------------------------------------------------------------|------------|------------------------------------------------|
| Georgia, Times New Roman                                    | Serif      | Hero titles, article headers, contact heading  |
| system-ui, -apple-system, Segoe UI, Roboto, sans-serif      | Sans-serif | Body text, paragraphs, headings                |
| ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas       | Monospace  | Code elements (code, pre, kbd, samp)           |
| Apple Color Emoji, Segoe UI Emoji, Noto Color Emoji         | Emoji      | Emoji fallback rendering                       |

## Bundled Theme Fonts (KaTeX — math rendering only)

- KaTeX_Main
- KaTeX_Math
- KaTeX_AMS
- KaTeX_Caligraphic
- KaTeX_Fraktur
- KaTeX_SansSerif
- KaTeX_Script
- KaTeX_Typewriter
- KaTeX_Size1, KaTeX_Size2, KaTeX_Size3, KaTeX_Size4
